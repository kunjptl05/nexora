Nexora Platform Architecture

1. Ingestion PDF & Text Ingestion → Heading & Boundary Chunker → Structured Claims
2. Storage Unified Knowledge Store: Dense Vector Embeddings + Keyword Index + Metadata
3. Hybrid Retrieval Dense Vector Similarity + Lexical Token Matching → Reciprocal Rank Fusion
4. Conflict Radar Cross-Document Claim Reconciliation (Numerical Deltas & Policy Amendments)
5. Grounded Synthesis Safe Abstention Verification → Clickable Citation Inspector → 100% Grounded
